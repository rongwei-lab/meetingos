# 座位表导出功能

## 功能说明

座位表导出功能允许管理员将当前座位布局导出为以下格式：
- **PNG 图片**：无损压缩，高质量，适合打印
- **JPEG 图片**：有损压缩，文件较小，适合网络传输
- **PDF 文档**：矢量格式，适合正式场合打印和存档

## 依赖安装

由于网络原因，导出功能所需的依赖包需要手动安装。请在网络正常时执行：

```bash
cd meetingos-admin
npm install html2canvas@^1.4.1 jspdf@^4.2.1
```

或使用淘宝镜像：

```bash
cd meetingos-admin
npm install html2canvas@^1.4.1 jspdf@^4.2.1 --registry=https://registry.npmmirror.com
```

## 使用方法

1. 进入"座位管理"页面
2. 点击右上角"导出座位表"按钮
3. 选择导出格式（PNG / JPEG / PDF）
4. 点击"导出"按钮
5. 浏览器会自动下载导出的文件

## 导出内容

导出的文件包含：
- 主席台/舞台区域
- 所有座位区域的完整布局
- 座位状态（空座、已分配、已签到、禁用）
- 座位编号或参会人姓名（根据当前显示模式）

## 技术实现

### 核心文件

1. **`src/utils/exportSeating.ts`**
   - 导出功能核心逻辑
   - 使用 html2canvas 将 DOM 转为 Canvas
   - 使用 jsPDF 生成 PDF 文档

2. **`src/types/export-libs.d.ts`**
   - html2canvas 和 jsPDF 的 TypeScript 类型声明
   - 在依赖未安装时提供类型支持

3. **`src/views/seating/SeatingView.vue`**
   - 添加了"导出座位表"按钮
   - 导出格式选择模态框
   - 导出进度提示

### 导出流程

```
用户点击"导出座位表"
    ↓
打开格式选择对话框
    ↓
用户选择格式（PNG/JPEG/PDF）
    ↓
准备导出：隐藏控制按钮、调整样式
    ↓
html2canvas 将座位图 DOM 转为 Canvas
    ↓
根据格式导出：
  - PNG/JPEG: Canvas.toBlob() → 下载
  - PDF: jsPDF.addImage() → 下载
    ↓
恢复原始状态
    ↓
显示成功提示
```

### 导出优化

- **高分辨率**：scale=2，确保导出清晰度
- **自动隐藏控件**：导出时隐藏缩放按钮等 UI 控件
- **自动命名**：文件名包含会议名称和时间戳
- **PDF 布局**：横向 A4 纸张，居中放置，保持宽高比
- **错误处理**：网络问题、DOM 问题等异常捕获和提示

## 注意事项

1. **依赖必须安装**：导出功能依赖 html2canvas 和 jsPDF，请确保已正确安装
2. **浏览器兼容性**：需要现代浏览器支持 Canvas API
3. **导出质量**：建议在缩放级别为 90%-100% 时导出，以获得最佳效果
4. **大型座位图**：座位数量较多时，导出可能需要几秒钟时间
5. **打印建议**：PDF 格式横向 A4 适合大多数打印场景

## 故障排查

### 问题：导出失败提示"未找到座位图元素"
**原因**：页面尚未完全加载或 DOM 引用丢失  
**解决**：刷新页面后重试

### 问题：导出的图片模糊
**原因**：scale 参数设置过低或浏览器缩放不当  
**解决**：检查 `exportSeating.ts` 中的 scale 参数（当前为 2）

### 问题：PDF 文件过大
**原因**：使用了 PNG 格式嵌入，未压缩  
**解决**：当前已使用 JPEG 格式嵌入 PDF（quality=0.95）

### 问题：依赖安装失败
**原因**：网络问题或 npm 源访问受限  
**解决**：
```bash
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com
npm install html2canvas jspdf

# 或临时使用
npm install html2canvas jspdf --registry=https://registry.npmmirror.com
```
