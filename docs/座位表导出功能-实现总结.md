## 🔧 技术实现

### 依赖库
- **html2canvas**: 将 DOM 元素转换为 Canvas
- **jsPDF**: 生成 PDF 文档

### 导出流程
```
用户操作 → 打开格式选择对话框 → 选择格式 → 
准备导出（隐藏控件）→ DOM 转 Canvas → 
根据格式生成文件 → 触发浏览器下载 → 恢复状态
```

### 关键参数
- **Canvas scale**: 2（2倍分辨率，确保清晰）
- **JPEG quality**: 0.95（95% 质量）
- **PDF 方向**: landscape（横向）
- **PDF 尺寸**: A4（297mm × 210mm）

## 📦 依赖安装

### 方法 1：自动安装脚本
```bash
./scripts/install-export-deps.sh
```

### 方法 2：手动安装
```bash
cd meetingos-admin
npm install html2canvas@^1.4.1 jspdf@^4.2.1
```

### 方法 3：使用镜像源
```bash
cd meetingos-admin
npm install html2canvas@^1.4.1 jspdf@^4.2.1 --registry=https://registry.npmmirror.com
```

## ⚠️ 注意事项

1. **依赖必须安装**：由于网络原因，html2canvas 和 jsPDF 需要在网络正常时手动安装
2. **类型声明文件**：在依赖未安装时，使用 `export-libs.d.ts` 提供类型支持，确保类型检查通过
3. **浏览器兼容性**：需要现代浏览器支持 Canvas API 和 Blob API
4. **导出性能**：大型座位图（超过 500 个座位）可能需要 3-5 秒导出时间

## 🎯 使用方法

1. 进入座位管理页面
2. 配置好座位布局和分配
3. 点击右上角"导出座位表"按钮
4. 选择导出格式（推荐 PDF 用于打印，PNG 用于分享）
5. 点击"导出"按钮
6. 等待导出完成，浏览器自动下载文件
