# 座位表导出功能 - 快速开始

## 📦 第一步：安装依赖

由于网络问题，依赖包需要在网络正常时手动安装。

### 方式 1：使用安装脚本（推荐）
```bash
./scripts/install-export-deps.sh
```

### 方式 2：手动安装
```bash
cd meetingos-admin
npm install html2canvas@^1.4.1 jspdf@^4.2.1
```

如果网络仍有问题，使用淘宝镜像：
```bash
cd meetingos-admin
npm install html2canvas@^1.4.1 jspdf@^4.2.1 --registry=https://registry.npmmirror.com
```

## 🎯 第二步：启动开发服务器

```bash
cd meetingos-admin
npm run dev
```

## 📸 第三步：使用导出功能

1. 在浏览器中打开座位管理页面
2. 点击右上角的 **"导出座位表"** 按钮
3. 在弹出的对话框中选择导出格式：
   - **PNG 图片**：无损压缩，高质量，适合打印
   - **JPEG 图片**：有损压缩，文件较小，适合网络传输
   - **PDF 文档**：横向 A4，适合正式场合打印和存档
4. 点击 **"导出"** 按钮
5. 浏览器会自动下载生成的文件

## 📋 导出的文件包含

- ✅ 主席台/舞台区域
- ✅ 所有座位区域的完整布局
- ✅ 座位状态（空座、已分配、已签到、禁用）
- ✅ 座位编号或参会人姓名（根据当前显示模式）

## 🎨 导出效果示例

**文件名格式**：
- `{会议名称}_座位表_2026-06-25_13-30.png`
- `{会议名称}_座位表_2026-06-25_13-30.jpg`
- `{会议名称}_座位表_2026-06-25_13-30.pdf`

**推荐使用场景**：
- 📄 **PDF**：会议现场打印、存档
- 🖼️ **PNG**：微信/邮件分享、高质量展示
- 📱 **JPEG**：快速传输、网络分享

## ⚠️ 注意事项

1. **首次使用前必须安装依赖**（html2canvas 和 jspdf）
2. 导出大型座位图（500+ 座位）可能需要 3-5 秒
3. 建议在座位缩放级别为 90%-100% 时导出
4. PDF 导出为横向 A4，适合大多数打印场景

## 🐛 遇到问题？

### 问题：点击导出按钮没有反应
**原因**：依赖未安装  
**解决**：运行 `./scripts/install-export-deps.sh` 安装依赖

### 问题：导出失败提示网络错误
**原因**：依赖安装时网络问题  
**解决**：使用淘宝镜像重新安装

### 问题：导出的图片模糊
**原因**：浏览器缩放级别过高或过低  
**解决**：将浏览器缩放调整到 100%
